Resource-Aware D3QN Framework for IoMT Intrusion Detection

A deep reinforcement learning framework addressing class imbalance and edge deployability constraints in Internet of Medical Things (IoMT) networks using 5 integrated optimization strategies.

🎯 Research Motivation: Resolving the Dual IoMT Gaps

Internet of Medical Things (IoMT) networks (e.g., patient monitors, automatic insulin pumps, ICU gateways) operate under strict hardware constraints while facing severe cyber threats. Prior literature exhibits two critical gaps:

Gap A: The Deployability Gap

Existing deep learning IDS models report high accuracy on server GPUs but fail to evaluate edge constraints (CPU latency, memory footprint, storage size). Heavy models cannot execute on low-power medical microcontrollers.

Gap B: The Class Imbalance Blind Spot

IoMT network flows are dominated by normal traffic and massive flood spams. Targeted lethal attacks (e.g., ICMP floods, host scanning, MQTT exploits) are extremely rare, causing standard AI models to achieve high accuracy by ignoring rare classes completely.

🧠 Neural Network Architecture (Conv1D + LSTM + Dueling Streams)

To process tabular flow features as sequential representations without spatial feature loss, our policy network combines a 1D Convolutional filter, a Recurrent LSTM cell, and a Dueling Q-head:

// Dueling Q-Value Combination Formula:
Q(s, a; θ, α, β) = V(s; θ, β) + ( A(s, a; θ, α) - &frac119; ∑a' A(s, a'; θ, α) )

⚙️ The 5 Integrated Technical Enhancement Strategies

1

Supervised Warm-Start Pretraining (15 Epochs)

Pretrains the CNN-LSTM feature representation using standard Cross-Entropy loss before DRL exploration. Reaches 76.08% classification accuracy prior to episode 1, preventing initial replay buffer poisoning by random exploration noise.

2

Dueling Double Deep Q-Network (D3QN)

Upgrades standard DQN to separate State Value $V(s)$ and Action Advantage $A(s,a)$ streams. Decouples general flow state quality from specific attack class decisions, reducing Q-value overestimation.

3

Contextual DRL ($\gamma = 0.0$) & Epsilon Calibration

Sets discount factor $\gamma = 0.0$ to model flow classification as a 1-step contextual bandit. Eliminates infinite Q-value accumulation ($Q > 500$) and maintains Q-scores strictly in $[-1, +1]$ logit margin space. Starts exploration at $\epsilon = 0.15$ to preserve pretrained weights.

4

Balanced Focal Reward Calibration

Formulates rewards using square-root smoothed inverse class frequencies ($w_c = \sqrt{N/N_c}$ normalized). Penalizes missing rare attacks proportionally without overwhelming majority benign class stability.

5

Selective Dynamic INT8 Quantization

Quantizes strictly nn.Linear projection layers while preserving nn.LSTM recurrent weights in FP32. Reduces binary file size to 0.44 MB while avoiding recurrent rounding noise (which previously dropped accuracy to 62%).

📐 Evaluation Metrics & Mathematical Definitions

Metric Mathematical Formulation Primary Role in Evaluation
Overall Accuracy Acc = (TP + TN) / (TP + TN + FP + FN) Overall flow classification ratio across all 130,000 samples
Macro Precision P_macro = (1/K) * ∑ (TP_k / (TP_k + FP_k)) Unweighted average precision across all 19 attack classes
Macro Recall R_macro = (1/K) * ∑ (TP_k / (TP_k + FN_k)) Primary detector metric measuring rare minority attack sensitivity
Macro F1-Score F1_macro = 2 * (P_macro * R_macro) / (P_macro + R_macro) Balanced quality indicator across imbalanced class distributions
Weighted F1-Score F1_weighted = ∑ (N_k / N_total) * F1_k Class-proportionate evaluation reflecting deployment flow density
CPU Inference Latency Latency = (1/N) * ∑ (t_end - t_start) Single-sample single-core CPU execution time (ms)
