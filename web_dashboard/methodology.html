⚡ RL Environment, Agent Architecture & Design

Resource-Aware D3QN Framework for IoMT Intrusion Detection

A deep reinforcement learning framework addressing class imbalance and edge deployability constraints in Internet of Medical Things (IoMT) networks using a custom Gymnasium MDP environment and Dueling Double DQN agent.

🎯 Research Motivation: Resolving the Dual IoMT Gaps

Internet of Medical Things (IoMT) networks (e.g., patient monitors, automatic insulin pumps, ICU gateways) operate under strict hardware constraints while facing severe cyber threats. Prior literature exhibits two critical gaps:

Gap A: The Deployability Gap

Existing deep learning IDS models report high accuracy on server GPUs but fail to evaluate edge constraints (CPU latency, memory footprint, storage size). Heavy models cannot execute on low-power medical microcontrollers.

Gap B: The Class Imbalance Blind Spot

IoMT network flows are dominated by normal traffic and massive flood spams. Targeted lethal attacks (e.g., ICMP floods, host scanning, MQTT exploits) are extremely rare, causing standard AI models to achieve high accuracy by ignoring rare classes completely.

🌐 Custom Gymnasium RL Environment Formulation (IoMTIDSEnv)

We frame tabular network flow classification as a 1-Step Contextual Markov Decision Process (MDP) defined by the 5-tuple $\langle S, A, P, R, \gamma \rangle$ built on top of the gymnasium.Env interface:

📐 Observation Space (State $S$)

gymnasium.spaces.Box(low=-inf, high=inf, shape=(25,), dtype=np.float32)

A continuous 25-dimensional feature vector $s \in \mathbb{R}^{25}$ representing a single network packet flow (IP flags, inter-arrival times, header lengths, port rates) standardized via Z-score scaling ($\mu=0, \sigma=1$).

🎮 Action Space (Action $A$)

gymnasium.spaces.Discrete(19)

19 discrete classification choices $a \in \{0, 1, \dots, 18\}$: $0$: Benign traffic, $1–18$: Specific IoMT attack categories (e.g., DoS-ICMP, MQTT Publish Flood, Spoofing-ARP, Recon-PortScan).

🔄 State Transitions & Discount ($\gamma=0.0$)

Contextual Bandit Setup: Setting discount factor $\gamma = 0.0$ models flow classification as a 1-step contextual decision. Eliminates infinite Q-value accumulation ($Q > 500$ under $\gamma=0.99$) and maintains Q-scores strictly in $[-1, +1]$ logit margin space.

⚖️ Balanced Focal Reward Function ($R$)

Normalized square-root inverse class weights $w_c = \sqrt{\frac{N}{N_c}}$:

$$r(s, a) = \begin{cases} +w_{\text{true\_class}} & \text{if } a = y_{\text{true}} \\ -w_{\text{true\_class}} \times \text{penalty} & \text{if } a \neq y_{\text{true}} \end{cases}$$

🔄 RL Agent-Environment Interaction Loop

🧠 Neural Architecture & D3QN Agent Specifications

To eliminate overestimation bias and decouple state risk from specific attack actions, our agent implements a 1D CNN + LSTM feature extractor coupled with a Dueling Double Q-learning architecture:

Dueling Q-Stream Decoupling

Splits Q-computation into scalar State Value $V(s)$ (general flow risk) and Action Advantage $A(s,a)$ (relative class logit):

$$Q(s, a; \theta, \alpha, \beta) = V(s; \theta, \beta) + \left( A(s, a; \theta, \alpha) - \frac{1}{|A|} \sum_{a'} A(s, a'; \theta, \alpha) \right)$$

Double Q-Learning Target (DDQN)

Uses Policy Net $\theta$ for action selection and Target Net $\theta^-$ for Q-evaluation, removing positive maximization bias:

$$Y_t^{\text{DDQN}} = r_t + \gamma \, Q\left(s_{t+1}, \arg\max_{a} Q(s_{t+1}, a; \theta); \theta^-\right)$$

Warm-Start $\epsilon$-Greedy Exploration

Starts exploration at $\epsilon = 0.15$ (after 15 pretraining epochs) decaying at rate $0.98$ down to $\epsilon_{\text{min}} = 0.01$. Preserves pretrained feature representations while refining boundaries.

Experience Replay & SGD Frequency

Maintains a FIFO transition buffer of capacity 10,000. Executes SGD updates every 4 steps ($\text{step} \pmod 4 == 0$) using Huber Loss ($\text{SmoothL1Loss}$) and AdamW optimizer ($\text{LR} = 10^{-3}$).

⚙️ Summary of the 5 Integrated Optimization Strategies

1

Supervised Warm-Start Pretraining (15 Epochs)

Pretrains the CNN-LSTM feature representation using standard Cross-Entropy loss before DRL exploration. Reaches 76.08% classification accuracy prior to episode 1, preventing initial replay buffer poisoning by random exploration noise.

2

Dueling Double Deep Q-Network (D3QN)

Upgrades standard DQN to separate State Value $V(s)$ and Action Advantage $A(s,a)$ streams. Decouples general flow state quality from specific attack class decisions, reducing Q-value overestimation.

3

Contextual DRL ($\gamma = 0.0$) & Epsilon Calibration

Sets discount factor $\gamma = 0.0$ to model flow classification as a 1-step contextual bandit. Eliminates infinite Q-value accumulation ($Q > 500$) and maintains Q-scores strictly in $[-1, +1]$ logit margin space. Starts exploration at $\epsilon = 0.15$ to preserve pretrained weights.

4

Balanced Focal Reward Calibration

Formulates rewards using square-root smoothed inverse class frequencies ($w_c = \sqrt{N/N_c}$ normalized). Penalizes missing rare attacks proportionally without overwhelming majority benign class stability.

5

Selective Dynamic INT8 Quantization

Quantizes strictly nn.Linear projection layers while preserving nn.LSTM recurrent weights in FP32. Reduces binary file size to 0.44 MB while avoiding recurrent rounding noise (which previously dropped accuracy to 62%).

📐 Evaluation Metrics & Mathematical Definitions

Metric Mathematical Formulation Primary Role in Evaluation
Overall Accuracy $$\text{Acc} = \frac{TP + TN}{TP + TN + FP + FN}$$ Overall flow classification ratio across all 130,000 samples
Macro Precision $$P_{\text{macro}} = \frac{1}{K} \sum_{k=1}^{K} \frac{TP_k}{TP_k + FP_k}$$ Unweighted average precision across all 19 attack classes
Macro Recall $$R_{\text{macro}} = \frac{1}{K} \sum_{k=1}^{K} \frac{TP_k}{TP_k + FN_k}$$ Primary detector metric measuring rare minority attack sensitivity
Macro F1-Score $$F1_{\text{macro}} = 2 \cdot \frac{P_{\text{macro}} \cdot R_{\text{macro}}}{P_{\text{macro}} + R_{\text{macro}}}$$ Balanced quality indicator across imbalanced class distributions
Weighted F1-Score $$F1_{\text{weighted}} = \sum_{k=1}^{K} \frac{N_k}{N_{\text{total}}} \cdot F1_k$$ Class-proportionate evaluation reflecting deployment flow density
CPU Inference Latency $$\text{Latency} = \frac{1}{N} \sum_{i=1}^{N} (t_{\text{end}} - t_{\text{start}})$$ Single-sample single-core CPU execution time (ms)
