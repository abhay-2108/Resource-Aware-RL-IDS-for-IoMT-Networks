🏥 1. The Core Problem: Cyber Security in Medical IoMT Networks

Modern hospital environments are increasingly reliant on connected Internet of Medical Things (IoMT) devices—such as automatic insulin pumps, wearable cardiac telemetry monitors, infusion gateways, and ICU ventilators. These devices monitor and control vital patient health functions in real time.

Severe Hardware Constraints

Medical edge devices run on small batteries or low-power microcontrollers (e.g., ARM Cortex-M, ESP32, STM32) with tiny RAM memory (KBs) and weak CPUs. They cannot host heavy Deep Learning models or GPU hardware.

Lethal Attack Threat Vectors

IoMT networks face sophisticated attacks including DoS/DDoS floods, ARP spoofing, reconnaissance vulnerability scans, and MQTT telemetry exploits that can tamper with patient medication dosages or disrupt ICU monitors.

⚠️ 2. Existing Solutions & Their Limitations

Standard Machine Learning (ML) and Deep Reinforcement Learning (DRL) intrusion detection systems in academic literature (2024–2026) report over 95% macro accuracy. However, they suffer from fundamental real-world flaws:

Existing Solution Approach How It Works Critical Engineering Flaw
Standard Machine Learning (Random Forest, XGBoost) Static supervised classification trained on offline tabular flow features Inflexible to evolving network conditions; requires manual feature extraction; ignores sequential flow dependencies
Standard Deep Learning (DNN, CNN, LSTM) Heavy deep neural networks trained with Cross-Entropy loss on server GPUs High computational footprint (>5 MB model size); zero edge latency profiling; collapses on severe class imbalance
Conventional DRL (Standard Flat DQN) DQN agent with flat reward function ($+1$ correct, $-1$ incorrect) Prioritizes overall dataset accuracy by predicting common benign traffic, resulting in 0.00% zero-detection recall on rare attacks

🔍 3. Identified Research Gaps (Gap A & Gap B)

Our literature survey identified two fundamental research gaps in IoMT security engineering:

Gap A: The Deployability Gap (Resource Unawareness)

Prior works evaluate models exclusively in high-resource GPU desktop/server environments and report no resource-cost metrics (such as single-core CPU latency per packet, peak RAM footprint, or model binary size). Whether these networks can run on resource-constrained medical edge gateways remains unverified in literature.

Gap B: The Class Imbalance Blind Spot

Clinical IoMT network traffic is heavily imbalanced, dominated by normal (benign) traffic and massive DDoS floods. Stealthy, highly targeted attacks (e.g., ICMP floods, host discovery, MQTT exploits) represent a tiny fraction of total flows. Standard models achieve high overall accuracy while remaining completely blind (0% detection) to stealthy attacks.

💡 4. Our Proposed Solution: The RA-RL-IDS Framework

To resolve both gaps simultaneously, we introduced RA-RL-IDS (Resource-Aware Reinforcement Learning Intrusion Detection System)—a class-imbalance-aware Dueling Double Deep Q-Network (D3QN) optimized for edge deployment using 5 integrated technical strategies:

1

Supervised Warm-Start Pretraining (15 Epochs)

Pretrains the CNN-LSTM feature extractor for 15 epochs using Cross-Entropy loss ($76.08\%$ accuracy), preventing initial replay buffer corruption from random exploration noise.

2

Dueling Double Deep Q-Network Architecture (D3QN)

Decouples scalar State Value $V(s)$ from Action Advantage $A(s,a)$ streams, preventing action-value overestimation across 19 attack categories.

3

Contextual DRL Formulation ($\gamma = 0.0$) & Epsilon Calibration

Sets discount factor $\gamma = 0.0$ to model flow classification as a 1-step contextual bandit, bounding Q-values in $[-1, +1]$ logit margin space and decaying exploration smoothly from $\epsilon = 0.15 \to 0.01$.

4

Balanced Focal Reward Calibration

Formulates rewards using normalized square-root inverse class weights $w_c = \sqrt{N/N_c}$, penalizing false negatives on rare attacks heavily without destabilizing majority benign traffic.

5

Selective Dynamic INT8 Quantization

Quantizes strictly nn.Linear projection layers while preserving nn.LSTM recurrent parameters in FP32. Achieves 0.44 MB file size and 6.08 ms CPU latency with zero accuracy loss (85.84%).
